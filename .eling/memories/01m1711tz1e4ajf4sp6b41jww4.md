[Convention] Cara Simulasi CRUD Memory oleh Agent:
1. Selalu gunakan tag prefix konsisten yang gampang diingat & gampang di-filter, misal:
   - #sim_crud → simulasi CRUD dasar
   - #realtime_test → uji SSE push realtime
   - #duplicate_test → uji dedup backend
   - #final_demo → demo end-to-end
   
2. Boleh tambahkan tag spesifik per fase (mis. #phase_updated, #verified) untuk narrowing.

3. SELALU bersihkan (delete) memory test yang dibuat di akhir simulasi sebelum pindah ke skenario lain, sehingga database .eling/memories/ tetap bersih 100% tanpa sisa.

4. Tujuan: setiap simulasi mengembalikan workspace ke kondisi fresh, tanpa memory test tertinggal di project scope.
