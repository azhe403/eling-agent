User rule (global): All agent skill installs must be managed by skillshare CLI, not `npx skills add` or manual copies. Workflow: `skillshare install <owner/repo> --track` then `skillshare sync`. Flag gotcha: `--track` conflicts with `--all`/`--yes`/`-s` — use bare `skillshare install repo --track`. Tracked-repo skills link as `_repo__skill` junctions in targets (archify = `~/.config/opencode/skills/_archify__archify`). Source: AppData\Roaming\skillshare\skills. Update later via `skillshare update _archify && skillshare sync`. First managed skill: tt-a1i/archify v2.15.
